# Выпуск новой версии

Автообновление в приложении читает **манифест** — маленький JSON с номером
версии и ссылкой на архив. Манифест лежит на GitHub Pages, архив — файлом
при релизе на GitHub.

## Разовая настройка

1. В репозитории: **Settings → Pages** → включить публикацию из ветки
   (например `gh-pages`, папка `/root`).
2. Проверить, что у клиента в `appsettings.json` указан адрес манифеста:

   ```json
   "Updates": {
     "ManifestUrl": "https://tashievemir.github.io/MyWarehouse/latest.json"
   }
   ```

   Ссылка обязана быть `https` — приложение отвергает `http`, потому что
   обновление приносит исполняемый код.

## Каждый выпуск

```powershell
.\tools\publish-release.ps1 `
    -Version 1.1.0 `
    -PackageUrl https://github.com/TashievEmir/MyWarehouse/releases/download/v1.1.0/MyWarehouse-1.1.0.zip `
    -Notes "Штрихкоды и этикетки, страница клиентов"
```

Скрипт поднимет версию в `Wpf.csproj`, соберёт Release, упакует и посчитает
SHA-256, затем положит в папку `release/`:

- `MyWarehouse-1.1.0.zip` — приложить к релизу на GitHub
- `latest.json` — залить на GitHub Pages

Порядок важен: **сначала архив, потом манифест**. Иначе клиент успеет увидеть
новую версию и получит 404 при скачивании.

## Что НЕ попадает в архив

| Файл | Почему |
|---|---|
| `appsettings.json` | Содержит пароль приложения от почты |
| `app.db` | Рабочая база клиента |
| `*.pdb` | Отладочные символы, клиенту не нужны |

Эти же файлы скрипт обновления не трогает у клиента: база и настройки
переживают любое количество обновлений.

## Если обновление не встало

Скрипт подмены пишет журнал рядом с временной папкой:

```
%TEMP%\MyWarehouse.update\<версия>-<id>\update.log
```

При сбое копирования он возвращает заменённые файлы из `backup\` и запускает
прежнюю версию — приложение не останется сломанным.

## Как это устроено внутри

```
Application          контракты и сравнение версий, без сети и файлов
  IUpdateFeed          откуда берём манифест
  IUpdateInstaller     как применяем
  IAppVersionProvider  какая версия запущена
  UpdateService        решает, есть ли что ставить

Infrastructure       реализации
  HttpUpdateFeed       HTTP + JSON
  ZipUpdateInstaller   скачать, сверить SHA-256, распаковать
  UpdateScript         подмена файлов, пока приложение закрыто

Wpf                  интерфейс
  AssemblyVersionProvider  версия из атрибутов сборки
  UpdatesViewModel         раздел «Обновление»
```

Менять хостинг можно не трогая логику: достаточно другой реализации
`IUpdateFeed`.
